# 微信分享功能实现

## 📋 概述

本文档详细说明如何在 uni-app 项目中实现微信小程序的分享功能，包括右上角原生分享和自定义分享面板。

## 🎯 功能需求

- ✅ 微信小程序右上角原生分享
- ✅ 分享给好友
- ✅ 分享到朋友圈
- ✅ 所有页面支持分享
- ✅ 动态分享内容（文章标题、封面图等）
- ✅ H5 环境的分享降级方案

---

## 🔧 技术方案

### 1. uni-app 分享 API

uni-app 提供了两个生命周期函数来处理分享：

```typescript
import { onShareAppMessage, onShareTimeline } from '@dcloudio/uni-app';

// 分享给好友
onShareAppMessage(() => {
  return {
    title: '分享标题',
    path: '/pages/index/index',
    imageUrl: '分享图片URL'
  };
});

// 分享到朋友圈
onShareTimeline(() => {
  return {
    title: '分享标题',
    query: 'id=123',
    imageUrl: '分享图片URL'
  };
});
```

### 2. 关键技术点

**重要约束**：
- `onShareAppMessage` 和 `onShareTimeline` **必须在页面的 setup 顶层直接调用**
- **不能在 composable 内部调用**这些生命周期函数
- 必须返回配置对象，不能返回 Promise

## 💻 核心实现

### 1. 分享配置 Composable

`src/composables/useShare.ts`:

```typescript
import type { PageShareConfig } from '@/types';

/**
 * 通用页面分享 Composable
 * 返回分享配置，需要在页面中手动调用 onShareAppMessage
 */
export function useShare(config?: PageShareConfig | (() => PageShareConfig)) {
  // 默认配置
  const defaultConfig: PageShareConfig = {
    title: '雅珲网',
    path: '/pages/index/index',
    imageUrl: '',
    desc: '分享来自雅珲网的精彩内容'
  };

  // 获取当前配置
  const getConfig = (): PageShareConfig => {
    if (typeof config === 'function') {
      return { ...defaultConfig, ...config() };
    }
    return { ...defaultConfig, ...config };
  };

  // 获取分享给好友的配置
  const getShareConfig = () => {
    const cfg = getConfig();
    const shareData: any = {
      title: cfg.title || defaultConfig.title,
      path: cfg.path || defaultConfig.path
    };

    // 只在有图片时才添加 imageUrl
    if (cfg.imageUrl) {
      shareData.imageUrl = cfg.imageUrl;
    }

    console.log('[分享给好友] 配置:', shareData);
    return shareData;
  };

  // 获取分享到朋友圈的配置
  const getTimelineConfig = () => {
    const cfg = getConfig();
    const shareData: any = {
      title: cfg.title || defaultConfig.title
    };

    // 添加查询参数
    if (cfg.query) {
      shareData.query = cfg.query;
    }

    // 只在有图片时才添加 imageUrl
    if (cfg.imageUrl) {
      shareData.imageUrl = cfg.imageUrl;
    }

    console.log('[分享到朋友圈] 配置:', shareData);
    return shareData;
  };

  return {
    getShareConfig,
    getTimelineConfig
  };
}

/**
 * 获取首页分享配置
 */
export function getIndexShareConfig() {
  return {
    title: '雅珲网 - 技术博客',
    path: '/pages/index/index'
  };
}

/**
 * 获取文章详情页分享配置
 */
export function getPostShareConfig(post: {
  title?: string;
  url?: string;
  cover?: string;
}) {
  const config: any = {
    title: post.title || '文章分享',
    path: post.url
      ? `/pages/post/detailraw?url=${encodeURIComponent(post.url)}`
      : '/pages/index/index'
  };

  if (post.cover) {
    config.imageUrl = post.cover;
  }

  return config;
}

/**
 * 获取分类页分享配置
 */
export function getCategoryShareConfig(category?: {
  name?: string;
  slug?: string;
}) {
  if (!category) {
    return {
      title: '文章分类 - 雅珲网',
      path: '/pages/category/list'
    };
  }

  return {
    title: category.name ? `${category.name} - 分类` : '文章分类',
    path: category.slug
      ? `/pages/category/posts?slug=${category.slug}`
      : '/pages/category/list'
  };
}

/**
 * 获取标签页分享配置
 */
export function getTagShareConfig(tag?: { name?: string; slug?: string }) {
  if (!tag) {
    return {
      title: '文章标签 - 雅珲网',
      path: '/pages/tag/list'
    };
  }

  return {
    title: tag.name ? `${tag.name} - 标签` : '文章标签',
    path: tag.slug ? `/pages/tag/posts?slug=${tag.slug}` : '/pages/tag/list'
  };
}

export function getArchiveShareConfig() {
```

### 2. 页面中使用分享

#### 静态配置页面（首页、分类、标签等）

```typescript
// src/pages/index/index.vue
<script setup lang="ts">
import { onShareAppMessage, onShareTimeline } from '@dcloudio/uni-app';
import { getIndexShareConfig } from '@/composables/useShare';

// 配置页面分享 - 必须在 setup 顶层调用
onShareAppMessage(() => getIndexShareConfig());
onShareTimeline(() => getIndexShareConfig());

// 其他代码...
</script>
```

#### 动态配置页面（文章详情）

```typescript
// src/pages/post/detailraw.vue
<script setup lang="ts">
import { ref } from 'vue';
import { onLoad, onShareAppMessage, onShareTimeline } from '@dcloudio/uni-app';
import { getPostShareConfig } from '@/composables/useShare';
import type { PostDetail } from '@/types';

const post = ref<PostDetail>({} as PostDetail);
const currentUrl = ref('');

// 配置页面分享 - 使用响应式数据
onShareAppMessage(() => getPostShareConfig({
  title: post.value.title,
  url: currentUrl.value,
  cover: post.value.cover
}));

onShareTimeline(() => getPostShareConfig({
  title: post.value.title,
  url: currentUrl.value,
  cover: post.value.cover
}));

// 加载文章数据...
onLoad(async (options: any) => {
  const url = decodeURIComponent(options.url);
  currentUrl.value = url;
  // 加载文章...
});
</script>
```

### 3. 分享工具类（H5 降级）

`src/utils/share.ts`:

```typescript
import type { ShareOptions, ShareResult, SharePlatform } from '@/types';

export class ShareUtil {
  /**
   * 获取当前平台
   */
  private static getPlatform(): string {
    // #ifdef MP-WEIXIN
    return 'mp-weixin';
    // #endif
    // #ifdef H5
    return 'h5';
    // #endif
    // #ifdef APP
    return 'app';
    // #endif
    return 'unknown';
  }

  /**
   * 分享到微信（小程序环境）
   */
  static shareToWeixin(_options: ShareOptions): ShareResult {
    const platform = this.getPlatform();

    if (platform === 'mp-weixin') {
      return {
        success: true,
        platform: 'weixin',
        message: '请点击右上角 ··· 按钮进行分享'
      };
    }

    return {
      success: false,
      platform: 'weixin',
      message: '当前环境不支持微信分享'
    };
  }

  /**
   * 复制链接
   */
  static copyLink(url: string): Promise<ShareResult> {
    return new Promise((resolve) => {
      uni.setClipboardData({
        data: url,
        success: () => {
          uni.showToast({
            title: '链接已复制',
            icon: 'success'
          });
          resolve({
            success: true,
            platform: 'copy'
          });
        },
        fail: () => {
          uni.showToast({
            title: '复制失败',
            icon: 'none'
          });
          resolve({
            success: false,
            platform: 'copy',
            message: '复制失败'
          });
        }
      });
    });
  }

  /**
   * 通用分享方法
   */
  static share(options: ShareOptions): Promise<ShareResult> {
    const platform = this.getPlatform();

    // 小程序环境：使用原生分享
    if (platform === 'mp-weixin') {
      uni.showToast({
        title: '请点击右上角分享',
        icon: 'none'
      });
      return Promise.resolve({
        success: true,
        platform: 'weixin'
      });
    }

    // H5 环境：使用 Web Share API 或复制链接
    if (platform === 'h5' && options.url) {
      // @ts-ignore
      if (navigator.share) {
        // @ts-ignore
        return navigator
          .share({
            title: options.title,
            text: options.content,
            url: options.url
          })
          .then(() => ({
            success: true,
            platform: 'h5' as SharePlatform
          }))
          .catch(() => this.copyLink(options.url!));
      } else {
        return this.copyLink(options.url);
      }
    }

    return Promise.resolve({
      success: false,
      platform: 'weixin',
      message: '当前环境不支持分享'
    });
  }
}
```

```vue
<template>
  <u-popup
    v-model:show="visible"
    mode="bottom"
    round="20"
    closeable
    @close="handleClose"
  >
    <view class="share-panel">
      <view class="panel-header">
        <text class="panel-title">分享到</text>
      </view>

      <view class="share-options">
        <!-- 微信分享 -->
        <view class="share-item" @click="handleShare('weixin')">
          <view class="share-icon weixin">
            <u-icon name="weixin" size="32" color="#fff" />
          </view>
          <text class="share-label">微信</text>
        </view>

        <!-- 朋友圈 -->
        <view class="share-item" @click="handleShare('moment')">
          <view class="share-icon moment">
            <u-icon name="moments" size="32" color="#fff" />
          </view>
          <text class="share-label">朋友圈</text>
        </view>

        <!-- 复制链接 -->
        <view class="share-item" @click="handleShare('copy')">
          <view class="share-icon copy">
            <u-icon name="copy" size="32" color="#fff" />
          </view>
          <text class="share-label">复制链接</text>
        </view>

        <!-- 生成海报 -->
        <view class="share-item" @click="handleShare('poster')">
          <view class="share-icon poster">
            <u-icon name="photo" size="32" color="#fff" />
          </view>
          <text class="share-label">生成海报</text>
        </view>
      </view>
    </view>
  </u-popup>
</template>

<script setup lang="ts">
import { computed } from 'vue';
import { ShareUtil } from '@/utils/share';
import type { SharePlatform } from '@/types';

interface Props {
  show: boolean;
  title: string;
  url: string;
  content?: string;
  imageUrl?: string;
}

const props = withDefaults(defineProps<Props>(), {
  content: '',
  imageUrl: ''
});

const emit = defineEmits<{
  (e: 'update:show', value: boolean): void;
  (e: 'share', platform: SharePlatform): void;
}>();

const visible = computed({
  get: () => props.show,
  set: (value) => emit('update:show', value)
});

const handleShare = async (platform: SharePlatform) => {
  if (platform === 'weixin' || platform === 'moment') {
    uni.showToast({
      title: '请点击右上角分享',
      icon: 'none'
    });
  } else if (platform === 'copy') {
    await ShareUtil.copyLink(props.url);
  } else if (platform === 'poster') {
    uni.showToast({
      title: '功能开发中',
      icon: 'none'
    });
  }

  emit('share', platform);
  visible.value = false;
};

const handleClose = () => {
  visible.value = false;
};
</script>
```

## ⚠️ 常见问题及解决方案

### 问题1: 显示"未设置分享"

**原因**：`onShareAppMessage` 没有在页面 setup 顶层调用

**错误示例**：
```typescript
// ❌ 在 composable 内部调用
export function useIndexShare() {
  onShareAppMessage(() => ({
    title: '首页'
  }));
}
```

**正确示例**：
```typescript
// ✅ 在页面 setup 顶层调用
import { onShareAppMessage } from '@dcloudio/uni-app';
import { getIndexShareConfig } from '@/composables/useShare';

onShareAppMessage(() => getIndexShareConfig());
```

### 问题2: 分享图片不显示

**原因**：传递了空字符串 `imageUrl: ''`

**解决方案**：
```typescript
// ✅ 只在有图片时才添加 imageUrl 字段
const shareData: any = {
  title: '标题',
  path: '/pages/index/index'
};

if (cover) {
  shareData.imageUrl = cover;
}

return shareData;
```

### 问题3: H5 环境分享不生效

**原因**：微信小程序的分享 API 只在小程序环境中有效

**解决方案**：
- 提供分享面板组件
- 使用 Web Share API 或复制链接作为降级方案

## 🎨 分享卡片优化建议

### 1. 分享图片规范

- 尺寸：500x400 或 5:4 比例
- 格式：jpg 或 png
- 大小：< 128KB
- 内容：清晰、有辨识度
