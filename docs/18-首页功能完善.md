# 首页功能完善

## 📋 概述

本文档介绍首页的功能实现，包括轮播图展示、快速导航栏、文章列表、分页加载等核心功能。

## 🎯 功能需求

- ✅ 轮播图展示推荐文章
- ✅ 快速导航入口（搜索、分类、标签）
- ✅ 文章列表展示
- ✅ 分页加载更多
- ✅ 下拉刷新
- ✅ 文章总数统计
- ✅ 加载状态提示
- ✅ 空状态处理

---

### 2. 逻辑实现

```typescript
<script setup lang="ts">
import { ref, onMounted } from 'vue';
import {
  onReachBottom,
  onShareAppMessage,
  onShareTimeline
} from '@dcloudio/uni-app';
import { api } from '@/api';
import PostItemComponent from '@/components/PostItem.vue';
import type { SwiperItem, PostItem } from '@/types';
import { getIndexShareConfig } from '@/composables/useShare';

// 配置页面分享
onShareAppMessage(() => getIndexShareConfig());
onShareTimeline(() => getIndexShareConfig());

// 数据定义
const swiperList = ref<SwiperItem[]>([]);
const posts = ref<PostItem[]>([]);
const currentPage = ref(1);
const totalPages = ref(1);
const hasMore = ref(true);
const loading = ref(true);
const loadingMore = ref(false);

// 页面挂载时加载数据
onMounted(async () => {
  try {
    // 并行加载轮播图和文章列表
    const [swiperRes] = await Promise.all([
      api.getSwiper(),
      loadPosts(1)
    ]);

    swiperList.value = swiperRes.data || [];
  } catch (err) {
    console.error('加载数据失败', err);
  } finally {
    loading.value = false;
  }
});

// 加载文章列表
const loadPosts = async (page: number) => {
  if (page > 1) loadingMore.value = true;

  try {
    const res = await api.getPosts(page);
    const newPosts = res.data.posts || res.data || [];

    if (page === 1) {
      posts.value = newPosts;
    } else {
      posts.value = [...posts.value, ...newPosts];
    }

    totalPages.value = res.data.total || res.data.totalPages || 1;
    hasMore.value = page < totalPages.value;
    currentPage.value = page;
  } catch (err) {
    console.error('加载文章失败', err);
    uni.showToast({ title: '加载失败', icon: 'none' });
  } finally {
    loadingMore.value = false;
  }
};

// 手动加载更多
const loadMore = () => {
  if (!loadingMore.value && hasMore.value) {
    loadPosts(currentPage.value + 1);
  }
};

// 触底自动加载更多
onReachBottom(() => {
  if (hasMore.value && !loadingMore.value) {
    loadPosts(currentPage.value + 1);
  }
});

// 跳转到文章详情
const toPost = (url: string) => {
  uni.navigateTo({
    url: `/pages/post/detailraw?url=${encodeURIComponent(url)}`
  });
};

// 跳转到普通页面
const toPage = (url: string) => {
  uni.navigateTo({ url });
};

// 跳转到 Tab 页面
const toTabPage = (url: string) => {
  uni.switchTab({ url });
};
</script>
```

### 1. 轮播图功能

**特性**：
- 自动播放（3秒间隔）
- 指示器显示当前位置
- 渐变遮罩保证文字可读性
- 点击跳转到文章详情

**优化点**：
```typescript

  text-shadow: 0 2rpx 4rpx rgba(0, 0, 0, 0.5);

```

### 2. 快速导航栏

**特性**：
- 三个快捷入口：搜索、分类、标签
- 图标 + 文字展示
- 点击反馈动画
- 圆角卡片设计

**交互优化**：
```css

  background: #f5f5f5;
  transform: scale(0.95);
}
```

### 3. 文章列表

**特性**：
- 复用 PostItem 组件
- 分页加载
- 手动加载更多
- 触底自动加载
- 加载状态提示

**数据流程**：
```
1. 页面加载 → 获取第一页
2. 手动点击 → 加载下一页
3. 滚动触底 → 自动加载下一页
4. 没有更多 → 显示提示
```

## ⚡ 性能优化

### 1. 并行加载

```typescript
// ✅ 并行加载轮播图和文章列表
const [swiperRes] = await Promise.all([
  api.getSwiper(),
  loadPosts(1)
]);

// ❌ 串行加载（慢）
const swiperRes = await api.getSwiper();
await loadPosts(1);
```

### 2. 防抖处理

```typescript
// 防止重复触发加载
const loadMore = () => {
  if (!loadingMore.value && hasMore.value) {
    loadPosts(currentPage.value + 1);
  }
};

onReachBottom(() => {
  if (hasMore.value && !loadingMore.value) {
    loadPosts(currentPage.value + 1);
  }
});
```

  lazy-load
  class="cover-image"

## 📊 数据流程

```
页面加载
    ↓
并行请求
├─ 获取轮播图 → swiperList
└─ 获取文章列表 → posts (第1页)
    ↓
显示内容
    ↓
用户滚动到底部
    ↓
触发 onReachBottom
    ↓
加载下一页
    ↓
追加到 posts 数组
    ↓
更新分页状态
```
