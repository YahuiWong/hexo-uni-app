# 分类和标签功能文档

## 📋 功能概述

本文档记录分类（Category）和标签（Tag）文章列表功能的实现细节，包括分类列表页、分类文章页、标签列表页和标签文章页。

## 🎯 功能特性

### 分类功能
- ✅ 分类列表展示（卡片式设计）
- ✅ 文章数量统计
- ✅ 分类图标显示
- ✅ 分类文章列表（分页加载）
- ✅ 空状态处理

### 标签功能
- ✅ 标签云展示
- ✅ 动态大小（基于文章数量）
- ✅ 多彩配色（8种颜色随机）
- ✅ 标签文章列表（分页加载）
- ✅ 空状态处理

## 💻 核心实现

### 1. 分类列表页 (category/list.vue)

#### 页面布局
```vue
<template>
  <view class="container">
    <!-- 加载中 -->
    <view v-if="loading" class="loading">
      <u-loading-icon mode="spinner" size="40" color="#007aff" />
    </view>

    <!-- 分类卡片列表 -->
    <view v-else class="category-list">
      <view
        v-for="category in categories"
        :key="category.name"
        class="category-card"
        @click="toCategory(category)"
      >
        <u-icon name="folder" size="40" color="#007aff" />
        <view class="category-info">
          <text class="category-name">{{ category.name }}</text>
          <text class="post-count">{{ category.count }} 篇文章</text>
        </view>
        <u-icon name="arrow-right" size="16" color="#ccc" />
      </view>
    </view>
  </view>
</template>
```

#### 核心逻辑
```typescript
const categories = ref<Category[]>([]);
const loading = ref(true);

onMounted(async () => {
  try {
    const res = await api.getCategories();
    categories.value = res.data || [];
  } catch (err) {
    console.error('加载分类失败', err);
    uni.showToast({ title: '加载失败', icon: 'none' });
  } finally {
    loading.value = false;
  }
});

const toCategory = (category: Category) => {
  uni.navigateTo({
    url: `/pages/category/posts?name=${encodeURIComponent(category.name)}&slug=${encodeURIComponent(category.slug)}`
  });
};
```

### 2. 分类文章列表页 (category/posts.vue)

#### 功能特点
- 接收 URL 参数：`name`（分类名称）和 `slug`（分类标识）
- 分页加载支持（触底自动加载）
- 复用 PostItem 组件展示文章
- 显示分类头部信息（名称 + 文章总数）

#### 核心代码
```typescript
const categoryName = ref('');
const categorySlug = ref('');
const posts = ref<any[]>([]);
const loading = ref(false);
const currentPage = ref(1);
const hasMore = ref(true);
const total = ref(0);

onLoad((options: any) => {
  if (options.name) {
    categoryName.value = decodeURIComponent(options.name);
  }
  if (options.slug) {
    categorySlug.value = decodeURIComponent(options.slug);
  }
  loadPosts();
});

const loadPosts = async () => {
  if (loading.value || !hasMore.value) return;

  loading.value = true;

  try {
    const res = await api.getCategoryPosts(categorySlug.value, currentPage.value);
    const newPosts = res.data?.posts || [];

    if (newPosts.length === 0) {
      hasMore.value = false;
    } else {
      posts.value = [...posts.value, ...newPosts];
      currentPage.value++;

      const totalPages = res.data?.total || 0;
      if (currentPage.value > totalPages) {
        hasMore.value = false;
      }
    }

    total.value = posts.value.length;
  } catch (err: any) {
    console.error('加载分类文章失败', err);
    uni.showToast({ title: '加载失败，请重试', icon: 'none' });
  } finally {
    loading.value = false;
  }
};

// 触底加载更多
onReachBottom(() => {
  if (hasMore.value && !loading.value) {
    loadPosts();
  }
});
```

### 3. 标签列表页 (tag/list.vue)

#### 标签云特性
- **动态大小**：根据文章数量计算标签尺寸
- **多彩配色**：8种颜色随机选择
- **文章数量角标**：显示每个标签的文章数

#### 样式计算逻辑
```typescript
const colors = [
  '#007aff', '#5ac8fa', '#34c759', '#ff9500',
  '#ff3b30', '#af52de', '#ff2d55', '#5856d6'
];

// 根据文章数量生成标签样式
const getTagStyle = (count: number) => {
  const maxCount = Math.max(...tags.value.map(t => t.count), 1);
  const minCount = Math.min(...tags.value.map(t => t.count), 1);

  // 计算标签大小（基于文章数量）
  const sizeRange = 20; // rpx
  const baseSize = 24; // rpx
  const ratio = (count - minCount) / (maxCount - minCount || 1);
  const fontSize = baseSize + ratio * sizeRange;

  // 随机选择颜色
  const color = colors[Math.floor(Math.random() * colors.length)];

  return {
    fontSize: `${fontSize}rpx`,
    backgroundColor: color,
    padding: `${12 + ratio * 8}rpx ${20 + ratio * 10}rpx`
  };
};

// 根据文章数量调整图标大小
const getIconSize = (count: number) => {
  const maxCount = Math.max(...tags.value.map(t => t.count), 1);
  const minCount = Math.min(...tags.value.map(t => t.count), 1);
  const ratio = (count - minCount) / (maxCount - minCount || 1);
  return 14 + ratio * 6; // 14-20
};
```

### 4. 标签文章列表页 (tag/posts.vue)

与分类文章列表页类似，区别在于：
- 使用标签颜色系统（动态配色）
- 头部图标和颜色根据标签动态变化
- 调用不同的 API 端点

#### 动态颜色实现
```typescript
const colors = [
  '#007aff', '#5ac8fa', '#34c759', '#ff9500',
  '#ff3b30', '#af52de', '#ff2d55', '#5856d6'
];

const tagColor = computed(() => {
  const index = tagName.value.length % colors.length;

});
```

## 🐛 已知问题与解决方案

### 问题1：URL 参数中文乱码
**解决方案**：使用 `encodeURIComponent` 和 `decodeURIComponent`

### 问题2：分页数据重复
**解决方案**：
- 使用展开运算符合并数组 `[...posts.value, ...newPosts]`
- 严格控制 `currentPage` 自增时机

### 问题3：触底加载触发过早
**解决方案**：
- 添加 `loading` 和 `hasMore` 双重判断
- 检查 `totalPages` 准确判断是否有更多数据

## 📊 性能优化
