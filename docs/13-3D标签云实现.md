# 13-3D标签云实现

## 概述

本文档介绍 Hexo UniApp 博客应用中 3D 标签云页面的实现细节，包括 Fibonacci 球面分布算法、3D 旋转变换、触摸交互等核心技术。

## 功能特性

### 核心功能

- **3D 球形标签云**：标签均匀分布在球面上，呈现立体效果
- **自动旋转**：标签云自动围绕 Y 轴旋转，展示完整的 3D 效果
- **触摸交互**：支持手势拖拽，可自由旋转标签云
- **近大远小**：基于 Z 轴深度动态调整标签大小和透明度
- **动态颜色**：多彩的标签配色方案
- **文章数量展示**：每个标签显示对应的文章数量
- **沉浸式体验**：全屏渐变背景，无导航栏

## 技术实现

### 1. Fibonacci 球面分布算法

使用 Fibonacci 球面分布算法确保标签均匀分布在球面上：

```typescript
const initTagCloud = () => {
  const tagCount = tags.value.length;
  const items: TagItem[] = [];

  tags.value.forEach((tag, index) => {
    // Fibonacci 球面分布算法
    const phi = Math.acos(-1 + (2 * index) / tagCount);
    const theta = Math.sqrt(tagCount * Math.PI) * phi;

    const x = radius * Math.cos(theta) * Math.sin(phi);
    const y = radius * Math.sin(theta) * Math.sin(phi);
    const z = radius * Math.cos(phi);

    items.push({ ...tag, x, y, z, scale: 1, opacity: 1, style: {} });
  });

  tagItems.value = items;
  updateTagPositions();
};
```

**算法优势**：
- 分布均匀，避免标签聚集
- 数学上精确，视觉效果优秀
- 性能优异，计算复杂度 O(n)

### 2. 3D 旋转变换

通过旋转矩阵实现 3D 旋转效果：

```typescript
const updateTagPositions = () => {
  const radX = (angleX.value * Math.PI) / 180;
  const radY = (angleY.value * Math.PI) / 180;

  tagItems.value = tagItems.value.map((tag, index) => {
    let x = tag.x;
    let y = tag.y;
    let z = tag.z;

    // 绕 Y 轴旋转
    const x1 = x * Math.cos(radY) - z * Math.sin(radY);
    const z1 = x * Math.sin(radY) + z * Math.cos(radY);

    // 绕 X 轴旋转
    const y2 = y * Math.cos(radX) - z1 * Math.sin(radX);
    const z2 = y * Math.sin(radX) + z1 * Math.cos(radX);

    // 计算缩放和透明度（近大远小）
    const scale = (radius + z2) / (2 * radius);
    const opacity = 0.4 + scale * 0.6;

    // 计算标签大小（基于文章数量）
    const maxCount = Math.max(...tags.value.map(t => t.count), 1);
    const minCount = Math.min(...tags.value.map(t => t.count), 1);
    const ratio = (tag.count - minCount) / (maxCount - minCount || 1);
    const fontSize = 14 + ratio * 10; // 14-24px

    const color = colors[index % colors.length];

    const style = {
      transform: `translate(-50%, -50%) translate3d(${x1}px, ${y2}px, ${z2}px) scale(${scale})`,
      opacity: opacity,
      zIndex: Math.floor(z2),
      fontSize: `${fontSize}px`,
      backgroundColor: color,
      boxShadow: `0 ${4 * scale}px ${12 * scale}px rgba(0, 0, 0, ${0.3 * opacity})`
    };

    return { ...tag, x: tag.x, y: tag.y, z: tag.z, scale, opacity, style };
  });
};
```

**关键技术点**：
- **旋转矩阵**：使用标准的 3D 旋转公式
- **透视效果**：基于 Z 轴深度计算缩放比例
- **层级关系**：使用 zIndex 确保正确的遮挡关系
- **居中对齐**：使用 `translate(-50%, -50%)` 确保元素中心对齐

### 3. 自动旋转

使用 `requestAnimationFrame` 实现流畅的自动旋转：

```typescript
const startAutoRotate = () => {
  const rotate = () => {
    if (autoRotate.value) {
      angleY.value += 0.2; // 每帧旋转 0.2 度
      updateTagPositions();
    }
    animationFrame = requestAnimationFrame(rotate);
  };
  rotate();
};
```

**性能优化**：
- 使用 `requestAnimationFrame` 而非 `setInterval`
- 每帧只旋转 0.2 度，流畅自然
- 在组件销毁时取消动画帧

### 4. 触摸交互

实现触摸拖拽旋转功能：

```typescript
const onTouchStart = (e: any) => {
  autoRotate.value = false;
  const touch = e.touches[0];
  touchStart.value = { x: touch.clientX, y: touch.clientY };
  lastAngle.value = { x: angleX.value, y: angleY.value };
};

const onTouchMove = (e: any) => {
  if (!touchStart.value) return;

  const touch = e.touches[0];
  const deltaX = touch.clientX - touchStart.value.x;
  const deltaY = touch.clientY - touchStart.value.y;

  angleY.value = lastAngle.value.y + deltaX * 0.5;
  angleX.value = lastAngle.value.x + deltaY * 0.5;

  // 限制 X 轴旋转角度（防止翻转）
  angleX.value = Math.max(-90, Math.min(90, angleX.value));

  updateTagPositions();
};

const onTouchEnd = () => {
  // 延迟 3 秒后恢复自动旋转
  setTimeout(() => {
    autoRotate.value = true;
  }, 3000);
};
```

**交互细节**：
- 触摸开始时暂停自动旋转
- 拖拽距离映射为旋转角度（系数 0.5）
- X 轴旋转限制在 -90° 到 90° 之间
- 触摸结束 3 秒后恢复自动旋转

### 5. 居中布局方案

使用视口单位和负边距确保完全居中：

```css
.container {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  overflow: hidden;
  margin: 0;
  padding: 0;
}

.tag-cloud {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 100vw;
  height: 100vh;
  margin-left: -50vw;  /* 负边距居中 */
  margin-top: -50vh;   /* 负边距居中 */
  perspective: 1200px;
  transform-style: preserve-3d;
}

.tag-item {
  position: absolute;
  left: 50%;
  top: 50%;
  /* transform 在 JS 中动态设置 */
}
```

**布局要点**：
- 使用 `100vw/100vh` 确保填满视口
- 负边距法实现精确居中
- `perspective: 1200px` 设置透视距离
- `transform-style: preserve-3d` 保持 3D 空间

## 性能优化

### 1. 动画性能

- 使用 `requestAnimationFrame` 而非定时器
- 每帧只更新必要的属性
- 使用 CSS `transform` 而非 `top/left`（GPU 加速）

### 2. 内存管理

```typescript
onUnmounted(() => {
  stopAutoRotate(); // 清理动画帧
});
```

### 3. 计算优化

- 三角函数结果缓存（radX, radY）
- 只在必要时重新计算标签位置
- 使用 `Map` 而非数组查找

## 常见问题

### 1. 标签云不居中

**原因**：容器或标签云定位不准确

**解决方案**：
```css
.tag-cloud {
  margin-left: -50vw;
  margin-top: -50vh;
}

.tag-item {
  transform: translate(-50%, -50%) translate3d(...);
}
```

### 2. 旋转不流畅

**原因**：每帧计算量过大

**解决方案**：
- 减少标签数量
- 降低旋转速度
- 使用 CSS `will-change` 提示浏览器优化

### 3. 触摸交互延迟

**原因**：事件处理过慢

**解决方案**：
```typescript
// 使用节流函数
const onTouchMove = throttle((e: any) => {
  // ... 处理逻辑
}, 16); // 60fps
```
