# 搜索功能文档

## 📋 功能概述

全局搜索功能允许用户通过关键词快速查找文章，支持标题和内容搜索，提供实时搜索结果展示。

## 🎯 功能特性

- ✅ 实时搜索（输入即搜）
- ✅ 搜索历史记录（本地存储）
- ✅ 搜索结果高亮关键词
- ✅ 热门搜索建议
- ✅ 空状态处理
- ✅ 搜索结果统计
- ✅ 清空搜索历史

### 2. 核心逻辑

```typescript
import { ref, onMounted } from 'vue';
import { api } from '@/api';

const keyword = ref('');
const searching = ref(false);
const results = ref<any[]>([]);
const allPosts = ref<any[]>([]);
const history = ref<string[]>([]);

// 热门搜索关键词
const hotKeywords = [
  'Docker', 'Vue', 'UniApp', 'TypeScript',
  'JavaScript', 'React', 'Node.js', 'Python'
];

onMounted(async () => {
  // 加载搜索历史
  const savedHistory = uni.getStorageSync('search_history') || [];
  history.value = savedHistory;

  // 预加载所有文章数据
  await loadAllPosts();
});

// 加载所有文章
const loadAllPosts = async () => {
  try {
    const res = await api.getSearch();
    allPosts.value = res.data || [];
  } catch (err) {
    console.error('加载搜索数据失败', err);
  }
};

// 执行搜索
const handleSearch = () => {
  if (!keyword.value.trim()) {
    results.value = [];
    return;
  }

  searching.value = true;

  // 模拟搜索延迟（实际是本地搜索）
  setTimeout(() => {
    const kw = keyword.value.toLowerCase().trim();

    results.value = allPosts.value.filter(post => {
      const titleMatch = post.title?.toLowerCase().includes(kw);
      const contentMatch = post.content?.toLowerCase().includes(kw);
      const excerptMatch = post.excerpt?.toLowerCase().includes(kw);
      return titleMatch || contentMatch || excerptMatch;
    });

    searching.value = false;

    // 保存搜索历史
    saveHistory(keyword.value);
  }, 300);
};

// 清空搜索
const handleClear = () => {
  keyword.value = '';
  results.value = [];
};

// 保存搜索历史
const saveHistory = (kw: string) => {
  if (!kw || !kw.trim()) return;

  // 去重并添加到历史记录开头
  const newHistory = [kw, ...history.value.filter(item => item !== kw)];

  // 限制历史记录数量
  history.value = newHistory.slice(0, 10);

  // 持久化存储
  uni.setStorageSync('search_history', history.value);
};

// 清空历史记录
const clearHistory = () => {
  uni.showModal({
    title: '提示',
    content: '确定清空搜索历史吗？',
    success: (res) => {
      if (res.confirm) {
        history.value = [];
        uni.removeStorageSync('search_history');
        uni.showToast({ title: '已清空', icon: 'success' });
      }
    }
  });
};

// 点击历史记录搜索
const searchHistory = (item: string) => {
  keyword.value = item;
  handleSearch();
};

// 点击热门关键词搜索
const searchKeyword = (item: string) => {
  keyword.value = item;
  handleSearch();
};

// 跳转到文章详情
const toPost = (post: any) => {
  let url = post.url;
  if (!url && post.date && post.slug) {
    const date = new Date(post.date);
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    url = `${year}/${month}/${day}/${post.slug}`;
  }

  if (url) {
    uni.navigateTo({
      url: `/pages/post/detail?url=${encodeURIComponent(url)}`
    });
  }
};

// 格式化日期
const formatDate = (dateStr: string) => {
  if (!dateStr) return '';
  const date = new Date(dateStr);
  return date.toLocaleDateString('zh-CN', {
    year: 'numeric',
    month: 'numeric',
    day: 'numeric'
  });
};
```

### 3. 关键词高亮

```typescript
// 高亮关键词（简化版，返回原文本）
const highlightKeyword = (text: string) => {
  if (!text || !keyword.value) return text;
  // 注意：rich-text 组件可以实现真正的高亮
  // 这里返回原文本，实际可以用 HTML 标记关键词
  return text;
};

// 如果要实现真正的高亮，可以这样：
const highlightKeywordHTML = (text: string) => {
  if (!text || !keyword.value) return text;
  const kw = keyword.value.trim();
  const regex = new RegExp(`(${kw})`, 'gi');
  return text.replace(regex, '<span style="color:#007aff;font-weight:bold;">$1</span>');
};
```

## 🔧 搜索优化

### 1. 搜索性能优化

```typescript
// 防抖搜索（避免频繁搜索）
import { ref } from 'vue';

let searchTimer: any = null;

const debouncedSearch = () => {
  clearTimeout(searchTimer);
  searchTimer = setTimeout(() => {
    handleSearch();
  }, 300);
};

// 使用防抖搜索
watch(keyword, () => {
  if (keyword.value) {
    debouncedSearch();
  } else {
    results.value = [];
  }
});
```

### 2. 搜索算法优化

```typescript
// 权重搜索（标题匹配权重高于内容）
const weightedSearch = (kw: string) => {
  const results = allPosts.value.map(post => {
    let score = 0;
    const lowerKw = kw.toLowerCase();

    // 标题完全匹配：10分
    if (post.title?.toLowerCase() === lowerKw) {
      score += 10;
    }
    // 标题包含关键词：5分
    else if (post.title?.toLowerCase().includes(lowerKw)) {
      score += 5;
    }

    // 摘要包含关键词：3分
    if (post.excerpt?.toLowerCase().includes(lowerKw)) {
      score += 3;
    }

    // 内容包含关键词：1分
    if (post.content?.toLowerCase().includes(lowerKw)) {
      score += 1;
    }

    // 标签匹配：2分
    if (post.tags?.some((tag: string) => tag.toLowerCase().includes(lowerKw))) {
      score += 2;
    }

    return { ...post, score };
  })
  .filter(post => post.score > 0)
  .sort((a, b) => b.score - a.score);

  return results;
};
```

## 🐛 已知问题与解决方案

### 问题1：搜索性能问题
**场景**：文章数量过多时搜索卡顿

**解决方案**：
- 使用 Web Worker 进行搜索（H5）
- 分页加载搜索结果
- 实现虚拟滚动

### 问题2：关键词高亮在 text 组件中无效
**原因**：text 组件不支持 HTML

**解决方案**：
- 使用 rich-text 组件
- 或者自定义高亮组件

### 问题3：搜索历史丢失
**原因**：未持久化存储

**解决方案**：
```typescript
// 使用 uni.setStorageSync 持久化
uni.setStorageSync('search_history', history.value);

// 页面加载时恢复
const savedHistory = uni.getStorageSync('search_history') || [];
history.value = savedHistory;
```
