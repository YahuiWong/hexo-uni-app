## ⚠️ 限制功能 (需要服务端配置)

### 2. Mermaid 图表渲染

**当前状态**: ⚠️ **占位符显示**

**显示效果**:
```
┌─────────────────────────────┐
│ Mermaid 代码（蓝色背景）     │
│ graph TD                     │
│   A-->B                      │
└─────────────────────────────┘
```

**为什么不在客户端渲染?**

我们尝试了客户端集成 Mermaid,但遇到以下问题:

1. **依赖地狱**:
   - Mermaid 11.x 有 **50+ 个依赖包**
   - 包括: `@mermaid-js/parser`, `cytoscape`, `d3` (30+ 子包), `dagre-d3-es`, `dompurify`, `elkjs`, `langium`, `roughjs`, 等等
   - 逐个安装 40+ 个包后仍然失败

2. **构建失败**:
   ```
   Could not resolve "@mermaid-js/parser"
   Could not resolve "cytoscape"
   Could not resolve "cose-base"
   Could not resolve "vscode-languageserver-types"
   ... (74+ 错误)
   ```

3. **包体积**:
   - Mermaid 核心库 > 2MB
   - 全部依赖 > 10MB
   - 对小程序包体积影响巨大

4. **towxml 方案失败**:
   - towxml 仅支持微信小程序 (WXML)
   - **不支持 uni-app**
   - **不支持 Mermaid** (仅支持 yuml)
   - 需要自定义构建

**推荐解决方案**: 📖 **Hexo 服务端预渲染**

详见: [30-Hexo服务端Mermaid配置指南.md](./30-Hexo服务端Mermaid配置指南.md)

**简要步骤**:

```bash
# 在 Hexo 博客根目录
npm install hexo-filter-mermaid-diagrams --save
```

配置 `_config.yml`:

```yaml
mermaid:
  enable: true
  theme: dark
```

重新生成:

```bash
hexo clean && hexo generate
```

**效果**:
- Mermaid 代码块会被转换为 `<svg>` 图形
- API 返回的 `content` 字段包含渲染好的 SVG
- UniApp 客户端 `mp-html` 组件直接显示,无需任何修改

### 3. KaTeX 数学公式渲染

**当前状态**: ⚠️ **占位符显示**

**显示效果**:
```
┌─────────────────────────────┐
│ LaTeX 代码（紫色背景）      │
│ $$E = mc^2$$                 │
└─────────────────────────────┘
```

**推荐解决方案**: 📖 **Hexo 服务端预渲染**

详见: [30-Hexo服务端Mermaid配置指南.md](./30-Hexo服务端Mermaid配置指南.md)

**简要步骤**:

```bash
npm uninstall hexo-renderer-marked --save
npm install hexo-renderer-markdown-it-plus --save
npm install markdown-it-katex --save
```

配置 `_config.yml`:

```yaml
markdown_it_plus:
  plugins:
    - markdown-it-katex
```

**效果**:
- LaTeX 公式会被转换为 HTML/CSS
- UniApp 客户端直接显示渲染好的公式

## 🎯 技术方案对比

| 功能 | 客户端实现 | 服务端预渲染 | 推荐方案 |
|------|-----------|-------------|---------|
| **代码高亮** | ✅ Prism.js (2KB) | ❌ | ⭐⭐⭐⭐⭐ 客户端 |
| **Mermaid 图表** | ❌ 依赖太多 (>10MB) | ✅ 零成本 | ⭐⭐⭐⭐⭐ 服务端 |
| **KaTeX 公式** | ❌ 包体积大 (~500KB) | ✅ 零成本 | ⭐⭐⭐⭐⭐ 服务端 |

**客户端实现适合**:
- 依赖少 (< 5 个包)
- 包体积小 (< 100KB)
- 需要交互功能
- 例如: Prism.js (仅 2KB, 无依赖)

**服务端预渲染适合**:
- 依赖多 (> 10 个包)
- 包体积大 (> 500KB)
- 渲染结果固定
- 例如: Mermaid (50+ 依赖, >10MB), KaTeX (~500KB)

## ⚠️ 已知限制

1. **Mermaid 交互功能**:
   - 服务端预渲染的 SVG 是静态的
   - 不支持点击节点、缩放等交互
   - 对于博客文章,静态图形已经足够

2. **数学公式编辑**:
   - 公式是预渲染的 HTML
   - 不支持实时编辑
   - 需要在 Markdown 源码中修改

3. **主题切换**:
   - Mermaid 主题在生成时确定
   - 不支持客户端动态切换
   - 可以在 Hexo 配置中更改主题后重新生成

## 🎨 自定义样式

### 代码块样式 (Okaidia 主题)

位置: `detail.vue` / `detailraw.vue`

```css
/* 修改代码块背景色 */
:deep(.mp-html pre) {
  background: #272822; /* Okaidia 深色 */
}

/* 修改关键字颜色 */
:deep(.mp-html .token.keyword) {
  color: #66d9ef; /* 青色 */
}
```

### Mermaid 图表样式

在 Hexo 主题 CSS 中:

```css
.mermaid {
  background: #f8f9fa;
  padding: 20px;
  border-radius: 8px;
}
```

或在 `_config.yml` 中选择主题:

```yaml
mermaid:
  theme: dark  # default, dark, forest, neutral
```
