# 微信小程序分享功能测试指南

## 问题现象

所有页面右上角显示"未设置分享"

## 已实施的修复

### 1. 修复返回值问题
- 移除空的 `imageUrl` 字段
- 只在有实际图片时才添加 `imageUrl`
- 添加调试日志输出

### 2. 修复动态配置
- 文章详情页的封面图处理
- 确保不传递空字符串

## 如何测试分享功能

### 方法1：微信开发者工具测试

1. **打开项目**
   ```bash
   # 构建微信小程序版本
   pnpm run dev:mp-weixin
   ```

2. **在微信开发者工具中打开**
   - 项目路径：`/dist/dev/mp-weixin`
   - 打开任意页面
   - 点击右上角"···"
   - 查看是否有"转发"选项

3. **查看控制台输出**
   - 打开微信开发者工具的控制台
   - 查找类似以下的输出：
     ```
     [分享给好友] 配置: {title: "雅珲网 - 技术博客", path: "/pages/index/index"}
     [分享到朋友圈] 配置: {title: "雅珲网 - 技术博客"}
     ```

### 方法2：真机测试

1. **预览小程序**
   - 在微信开发者工具中点击"预览"
   - 用微信扫码

2. **测试分享**
   - 打开任意页面
   - 点击右上角"···"
   - 点击"转发给朋友"或"分享到朋友圈"
   - 检查分享卡片的标题和图片

### 方法3：H5 测试（限制）

**注意**：H5 环境中微信小程序的分享 API 不会生效。需要使用页面底部的"分享文章"按钮。

## 可能的问题和解决方案

### 问题1：仍然显示"未设置分享"

**可能原因**：
1. 在 H5 环境中测试（H5 不支持小程序分享 API）
2. 微信开发者工具版本过旧
3. 页面刷新后配置未重新加载

**解决方案**：
1. 确保在微信开发者工具中测试
2. 更新微信开发者工具到最新版本
3. 重新编译项目：`pnpm run dev:mp-weixin`
4. 在微信开发者工具中点击"编译"重新加载

### 问题2：分享卡片没有图片

**原因**：该页面确实没有配置图片

**解决方案**：
- 对于列表页（首页、分类、标签等），可以添加默认分享图
- 对于文章详情页，确保文章有封面图

### 问题3：控制台看不到日志

**解决方案**：
1. 打开微信开发者工具的"控制台"标签页
2. 确保没有过滤掉 console.log
3. 进入页面时会自动输出配置信息

### 问题4：路径跳转错误

**检查**：
- 查看控制台输出的 `path` 字段
- 确保路径格式正确（如 `/pages/index/index`）
- 确保查询参数正确编码

## 添加默认分享图（可选）

如果想为所有页面添加默认分享图：

### 1. 准备分享图
- 尺寸建议：500x400 或 5:4 比例
- 格式：jpg 或 png
- 存放位置：`src/static/share.jpg`

### 2. 修改 useShare.ts

```typescript
const defaultConfig: PageShareConfig = {
  title: '雅珲网',
  path: '/pages/index/index',
  imageUrl: '/static/share.jpg',  // 添加默认图片
  desc: '分享来自雅珲网的精彩内容'
};
```

## 调试技巧

### 1. 查看分享配置
在页面的 script setup 中添加：
```typescript
const share = useIndexShare();
console.log('分享配置:', share.shareConfig.value);
```

### 2. 手动测试分享配置
```typescript
import { onShareAppMessage } from '@dcloudio/uni-app';

onShareAppMessage(() => {
  console.log('触发分享');
  return {
    title: '测试标题',
    path: '/pages/index/index'
  };
});
```

### 3. 检查生命周期
确保 `onShareAppMessage` 在 setup 的顶层调用，不要放在：
- if/else 条件中
- 函数内部
- 异步回调中
