# 夜间模式实现指南

本文档介绍 Hexo UniApp 博客应用的夜间模式（深色模式）实现方案。

## 功能概述

夜间模式提供了浅色和深色两种主题，用户可以在"我的"页面自由切换。主题设置会自动保存到本地，下次打开应用时自动应用上次选择的主题。

## 技术实现

### 1. 主题管理 Composable

**文件**: `src/composables/useTheme.ts`

提供了完整的主题管理功能：

```typescript
import { useTheme } from '@/composables/useTheme';

const { themeMode, toggleTheme, setTheme, isDark, getCurrentColors } = useTheme();
```

**主要功能**：

- `themeMode`: 当前主题模式（'light' | 'dark'）
- `toggleTheme()`: 切换主题（浅色 ↔ 深色）
- `setTheme(theme)`: 设置指定主题
- `isDark()`: 判断是否为深色模式
- `getCurrentColors()`: 获取当前主题的颜色配置

### 2. 主题颜色配置

支持的颜色变量：

| 变量类型 | 浅色主题 | 深色主题 | 说明 |
|---------|---------|---------|------|
| 背景色 | #ffffff | #1c1c1e | 主背景 |
| 背景色（次级） | #f5f5f5 | #2c2c2e | 次级背景 |
| 背景色（三级） | #f8f8f8 | #3a3a3c | 三级背景 |
| 文字颜色（主要） | #333333 | #ffffff | 主要文字 |
| 文字颜色（次要） | #666666 | #ebebf5 | 次要文字 |
| 文字颜色（三级） | #999999 | #8e8e93 | 三级文字 |
| 边框颜色 | #f0f0f0 | #38383a | 主边框 |
| 主题色 | #007aff | #0a84ff | 品牌主色 |
| 成功色 | #34c759 | #32d74b | 成功状态 |
| 警告色 | #ff9500 | #ff9f0a | 警告状态 |
| 危险色 | #ff3b30 | #ff453a | 危险状态 |

### 3. CSS 变量系统

**文件**: `src/styles/theme.css`

使用 CSS 变量定义主题颜色，在应用中全局可用：

```css
/* 使用示例 */
.container {
  background: var(--bg-primary);
  color: var(--text-primary);
}

.card {
  background: var(--bg-secondary);
  border: 1px solid var(--border-primary);
}

.button {
  background: var(--color-primary);
  color: #fff;
}
```

### 4. 应用初始化

**文件**: `src/App.vue`

应用启动时自动初始化主题：

```typescript
import { useTheme } from "@/composables/useTheme";

const { initTheme } = useTheme();

onLaunch(() => {
  initTheme(); // 从本地存储加载主题设置
});
```

### 5. 主题切换入口

**文件**: `src/pages/mine/index.vue`

在"我的"页面提供主题切换开关：

```vue
<template>
  <view class="menu-item" @click="toggleTheme">
    <view class="menu-left">
      <u-icon :name="isDark ? 'sun' : 'moon'" size="20" color="#ff9500" />
      <text class="menu-text">{{ isDark ? '浅色模式' : '深色模式' }}</text>
    </view>
    <u-icon name="arrow-right" size="16" color="#ccc" />
  </view>
</template>

<script setup>
import { computed } from 'vue';
import { useTheme } from '@/composables/useTheme';

const { themeMode, toggleTheme: switchTheme } = useTheme();
const isDark = computed(() => themeMode.value === 'dark');

const toggleTheme = () => {
  switchTheme();
  uni.showToast({
    title: isDark.value ? '已切换到深色模式' : '已切换到浅色模式',
    icon: 'none'
  });
};
</script>
```

## 使用指南

### 在新页面中应用主题

1. **使用 CSS 变量（推荐）**

```vue
<style scoped>
.page-container {
  background: var(--bg-primary);
  color: var(--text-primary);
}

.card {
  background: var(--bg-secondary);
  border: 1px solid var(--border-primary);
  box-shadow: 0 2px 8px var(--shadow-light);
}

.title {
  color: var(--text-primary);
}

.description {
  color: var(--text-secondary);
}
</style>
```

2. **动态样式（适用于复杂场景）**

```vue
<script setup>
import { computed } from 'vue';
import { useTheme } from '@/composables/useTheme';

const { getCurrentColors } = useTheme();
const colors = computed(() => getCurrentColors());
</script>

<template>
  <view :style="{
    background: colors.bgPrimary,
    color: colors.textPrimary
  }">
    动态主题内容
  </view>
</template>
```

### 在组件中响应主题变化

```vue
<script setup>
import { watch } from 'vue';
import { useTheme } from '@/composables/useTheme';

const { themeMode } = useTheme();

watch(themeMode, (newTheme) => {
  console.log('主题已切换为:', newTheme);
  // 执行主题切换后的逻辑
});
</script>
```

## 最佳实践

### 1. 颜色选择

- ✅ **推荐**：使用 CSS 变量（`var(--bg-primary)`）
- ❌ **不推荐**：硬编码颜色值（`#ffffff`）

### 2. 对比度

确保深色模式下的文字和背景有足够的对比度：

```css
/* 好的做法 */
.text {
  color: var(--text-primary); /* 自动适配主题 */
}

/* 不好的做法 */
.text {
  color: #666; /* 深色模式下可能看不清 */
}
```

### 3. 图片资源

对于需要适配主题的图标：

```vue
<template>
  <!-- 使用 uview-plus 图标，颜色可动态控制 -->
  <u-icon
    name="home"
    :color="isDark ? '#fff' : '#333'"
  />

  <!-- 或使用 CSS 变量 -->
  <u-icon
    name="home"
    color="var(--text-primary)"
  />
</template>
```

### 4. 渐变背景

某些特殊背景（如头部渐变）可能不需要跟随主题：

```css
.header {
  /* 保持固定的渐变色，不跟随主题 */
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  color: #fff; /* 固定为白色 */
}
```

## 本地存储

主题设置存储在本地 Storage 中：

- **Key**: `app_theme`
- **Value**: `'light'` | `'dark'`

清除缓存时会保留主题设置：

```typescript
const clearCache = () => {
  const savedTheme = uni.getStorageSync('app_theme');
  uni.clearStorageSync();
  if (savedTheme) {
    uni.setStorageSync('app_theme', savedTheme);
  }
};
```

## 常见问题

### 1. 主题切换后页面没有更新？

确保：
- 已在 App.vue 中导入 `theme.css`
- 样式使用了 CSS 变量而不是硬编码颜色
- 组件使用了 `scoped` 样式

### 2. 小程序中 TabBar 颜色没有变化？

这是平台限制。小程序的 TabBar 样式修改支持有限，建议：
- 使用自定义 TabBar
- 或接受默认的 TabBar 样式

### 3. 如何添加自定义主题颜色？

编辑 `src/styles/theme.css`：

```css
page {
  --custom-color: #your-light-color;
}

page.dark {
  --custom-color: #your-dark-color;
}
```

然后在组件中使用：

```css
.my-element {
  color: var(--custom-color);
}
```
